# ЛР5 — Прогноз погоды

Учебное приложение Flutter по ТЗ «ЛР05_Погода.docx».
Используется Open-Meteo без ключа API для учебного некоммерческого использования.
Интерфейс и состояние отделены от запросов и разбора данных.

## Возможности

- Поиск города на русском и других языках.
- Выбор по стране и региону, если найдено несколько городов.
- Текущие температура, описание погоды, значок, влажность, скорость ветра и доступное давление.
- Прогноз на пять дней: сегодня и следующие четыре дня, минимальная и максимальная температура.
- Состояния загрузки, успеха, ошибки и пустого результата.
- Проверка пустого ввода и повтор запроса при ошибке.
- Обновление погоды кнопкой вверху.
- Дополнительное задание из ТЗ: **избранные города** с локальным сохранением.
- Тёмная тема, прокрутка и ограничение ширины на больших экранах.

Температура — °C, ветер — м/с, давление — гПа. Давление не переводится в мм рт. ст.
Время данных и дни прогноза соответствуют местному времени выбранного города.
Описание получается из числового кода WMO; значки встроены во Flutter.

## Запуск

Из папки `l5_weather`:

```powershell
flutter pub get
flutter run -d chrome --web-port 8755 --web-hostname 127.0.0.1
```

Или запуск сервера с открытием страницы вручную:

```powershell
flutter run -d web-server --web-port 8755 --web-hostname 127.0.0.1
```

Адрес: http://127.0.0.1:8755. Перед запуском останови предыдущий сервер на этом порту.
Для Android подключи устройство и выбери его через `flutter run`.
Разрешение `INTERNET` добавлено в основной AndroidManifest, в том числе для release-сборки.

## Как пользоваться

1. Ввести город и нажать поиск или Enter на клавиатуре.
2. Если результат один, погода загрузится сразу. Иначе выбрать город из списка.
3. Нажать звезду в карточке, чтобы сохранить город в избранном.
4. Ниже прогноза находятся избранные города. Нажатие загружает погоду по сохранённым координатам.
5. Для удаления нажать крестик у избранного города либо повторно звезду в карточке погоды.

`shared_preferences`, знакомый по ЛР3 и ЛР4, сохраняет избранные города; в браузере это LocalStorage.
Сохраняются название, ID, регион, страна и координаты. Сама погода не кэшируется: для неё нужен интернет.
При повторном запуске используй тот же браузер и адрес, включая порт. Очистка данных сайта удаляет избранное.

## Структура

`WeatherScreen → WeatherState → WeatherRepository → WeatherApiClient`.

| Файл в `lib/` | Назначение |
| --- | --- |
| `main.dart` | Запуск приложения и тёмная тема |
| `models/city.dart` | Город, координаты и преобразование JSON |
| `models/weather.dart` | Текущая погода и список прогноза |
| `models/forecast_day.dart` | Прогноз одного дня |
| `data/weather_api_client.dart` | HTTPS-запросы, HTTP-коды, тайм-аут и ошибки сети |
| `repositories/weather_repository.dart` | Создание моделей из JSON |
| `repositories/favorites_repository.dart` | Чтение, добавление и удаление избранных городов |
| `weather_display.dart` | Описание, значок, оформление температуры и даты |
| `pages/weather_screen.dart` | Состояние экрана, поиск и отображение данных |

Пакет `http` выбран по примеру из документации Flutter, указанному в ТЗ.
Provider, Bloc, генераторы моделей, геолокация и библиотеки графиков не используются.
Объяснения кода и вопросы: [LAB5_DEFENSE_GUIDE.md](LAB5_DEFENSE_GUIDE.md).

## Проверка

```powershell
flutter analyze
flutter test
flutter build web
```

20.10.2026: анализатор без замечаний, **31 тест успешно**, web-сборка выполнена.
Проверены пустой запрос, неизвестный город, выбор одноимённого города, HTTP 404/500/429/403,
отсутствие связи, тайм-аут, неверный JSON, повтор запроса, показатели и прогноз, сохранение избранного и ошибки хранения.
Также проверены экран 320×568, масштаб текста 1,5, длинные названия, клавиатура и отсутствие давления.

Дополнительно код репозитория выполнил настоящие запросы: Ханты-Мансийск найден, погода с пятью днями прогноза получена,
для вымышленного города получен пустой результат. Вид экрана просмотрен по тестовым изображениям 390×844 и 1200×800.
В автотестах сеть и хранилище подменяются. Реальное отключение интернета на устройстве, ручной сценарий
в браузере и запуск на Android не проверялись.
